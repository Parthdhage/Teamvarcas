# Team Varcas

The Team Varcas website is a React application for presenting the team, its work, sponsors, and contact information.

## Technology

- React 19
- Vite
- Bootstrap
- Framer Motion

## Repository layout

    src/                  Application components and styles
    src/components/       Page sections including About, Team, Gallery, Sponsors, and Contact
    public/images/        Website imagery
    index.html            HTML entry point
    website_content.html  Standalone content reference
    website_styles.css    Standalone stylesheet reference
    website_script.js     Standalone script reference

## Run locally

Prerequisites: Node.js and npm.

    npm install
    npm run dev

Use the local URL printed by Vite. To create a production build:

    npm run build

To run the configured linter:

    npm run lint

## Project scope

The files in website_content.html, website_styles.css, and website_script.js are kept in the repository alongside the Vite application. This README describes the current layout without moving or changing those files.
